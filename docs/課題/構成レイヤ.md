# 構成レイヤ

歌詞・ボーカルは生成しないギター・インスト向け。区間名だけ定番の曲構成語彙（イントロ・Aメロ・Bメロ・間奏・サビ・アウトロ）を借りる。

> 最終更新: 2026-08-06（v2: 区間進行対比 + form_manifest / gate）

## 役割の切り分け

| レイヤ | 決めること | 状態 |
|--------|------------|------|
| 短い条件 prior | 曲の色（**home 進行**・キー・BPM・全体の盛り） | あり |
| **構成** | 区間の並び・長さ・区間進行・beat_type・盛り上げ | **本実装 v2** |
| 演奏 | 区間条件の下で各パートを鳴らす | 8小節単位 |
| ViTex | 生成後の符号付与 | 後段 |

キー・BPM は曲通し固定。進行は **mode（major / natural_minor）を変えず** 区間ごとにカタログから対比させる。

## 区間

| 役割 | 進行 | 盛り上がり | bars |
|------|------|------------|------|
| イントロ | home | 低 | 8 |
| Aメロ | home（提示・回帰とも） | 中 | 8 |
| Bメロ | contrast（同 mode ≠ home） | 中 | 8 |
| 間奏 | contrast | 中 | 8 |
| サビ | contrast | 高 | 8（v1。16は未検証） |
| アウトロ | home | 低 | 8 |

## テンプレ（v1）

1. short: イントロ → Aメロ → サビ → アウトロ
2. standard: イントロ → Aメロ → Bメロ → Aメロ → サビ → アウトロ
3. extended: イントロ → Aメロ → 間奏 → Bメロ → サビ → Aメロ → アウトロ

## 学習データ化（ルール → 評価 → 将来学習）

```
generate_form
  → midi/form_*.mid + form_*.json（sections / gate=pending）
  → scripts/form_gate_server.py（A/R/score）
  → data/form_candidates/candidates.jsonl（--export）
  → （将来）セクション進行 prior 学習
```

初期正解はルール（同 mode contrast）。人が accept した組み合わせを正解として積み上げ、後から学習に差し替える。

## 入口

`prttype/generate_form.py`  
評価 UI: `prttype/scripts/form_gate_server.py`（port 8766）

## API

```python
sample_song_form(
    home_progression=...,  # 必須
    home_mode=...,         # 必須（major / natural_minor）
    seed=...,
)
```

未渡しは TypeError / ValueError。呼び出し元は `generate_form.py` のみ。
