# 構成レイヤ

歌詞・ボーカルは生成しないギター・インスト向け。区間 role は SongFormer 語彙に統一。

> 最終更新: 2026-11-11（SongFormer 語彙統一 + lead 区間条件）

## 役割の切り分け

| レイヤ | 決めること | 状態 |
|--------|------------|------|
| 短い条件 prior | 曲の色（**home 進行**・キー・BPM・全体の盛り） | あり |
| **構成** | 区間の並び・長さ・区間進行・beat_type・盛り上げ | **本実装 v2** |
| 演奏 | 区間条件の下で各パートを鳴らす | 8小節単位。lead は section one-hot（20ch） |
| ViTex | 生成後の符号付与 | 後段 |

キー・BPM は曲通し固定。進行は **mode（major / natural_minor）を変えず** 区間ごとにカタログから対比させる。

## 区間

| role | 表示 | 進行 | 盛り上がり | bars |
|------|------|------|------------|------|
| `intro` | イントロ | home | 低 | 8 |
| `verse` | Aメロ | home（提示・回帰とも） | 中 | 8 |
| `pre_chorus` | Bメロ | contrast（同 mode ≠ home） | 中 | 8 |
| `bridge` | 間奏 | contrast | 中 | 8 |
| `chorus` | サビ | contrast | 高 | 8（v1。16は未検証） |
| `inst` | インスト | contrast | 中 | 8 |
| `outro` | アウトロ | home | 低 | 8 |

## テンプレ（v1）

1. short: intro → verse → chorus → outro
2. standard: intro → verse → pre_chorus → verse → chorus → outro
3. extended: intro → verse → bridge → pre_chorus → chorus → verse → outro

## lead 区間条件

- 学習: AnimeTAB（人手 I/A/B/C）+ SynthTab×SongFormer（自動）
- 入力: tonal11 + BPM + power + section one-hot7 = **20ch**
- 生成: `generate_form` が各区間の `section.role` を lead に渡す（ckpt `in_channels>=20` のとき）

## 学習データ化（ルール → 評価 → 将来学習）

```
generate_form
  → midi/form_*.mid + form_*.json（sections / gate=pending）
  → scripts/form_gate_server.py（A/R/score）
  → data/form_candidates/candidates.jsonl（--export）
  → （将来）セクション進行 prior 学習
```

## 入口

`prttype/generate_form.py`  
評価 UI: `prttype/scripts/form_gate_server.py`（port 8766）

## API

```python
sample_song_form(
    home_progression=...,  # 必須
    home_mode=...,         # 必須（major / natural_minor）
    seed=...,
)
```

未渡しは TypeError / ValueError。呼び出し元は `generate_form.py` のみ。
