# 構成レイヤ

歌詞・ボーカルは生成しないギター・インスト向け。区間名だけ定番の曲構成語彙（イントロ・Aメロ・Bメロ・間奏・サビ・アウトロ）を借りる。

## 役割の切り分け

| レイヤ | 決めること | 状態 |
|--------|------------|------|
| 短い条件 prior | 曲の色（進行系統・キー・BPM・全体の盛り） | あり |
| **構成** | 区間の並び・長さ・区間ごとの盛り上げ | **本実装** |
| 演奏 | 区間条件の下でバッキングを鳴らす | 8小節単位 |
| ViTex | 生成後の符号付与 | 後段 |

テンプレ抽選は「学習 prior 完成」ではない。区間注釈データが揃ったら学習サンプラに差し替える受け皿。

## 区間

| 役割 | 意味 | 盛り上がり |
|------|------|------------|
| イントロ | 入り | 低（疎） |
| Aメロ | メインの提示 | 中 |
| Bメロ | 対比の第二テーマ | 中 |
| 間奏 | つなぎ | 中 |
| サビ | 山場 | 高（密） |
| アウトロ | 終わり | 低（疎） |

盛り上がりはデコード側の疎密（閾値・最小間隔・隙間）に反映。U-Net 条件チャンネル化は次の段。

## テンプレ（v1）

目標尺は定めない（テンプレ小節数のまま。2〜3分は保証しない）。1ブロック＝8小節。

1. イントロ → Aメロ → サビ → アウトロ（32小節）
2. イントロ → Aメロ → Bメロ → Aメロ → サビ → アウトロ（48小節）
3. イントロ → Aメロ → 間奏 → Bメロ → サビ → Aメロ → アウトロ（56小節）

曲を通してキー・テンポ・進行は固定。変えるのは役割・長さ・区間盛り上がりのみ。

## 出力

最終 MIDI は **1本**。セクションはメモリ上で生成し、小節オフセットを加算して連結。途中ファイルは書かない。モデルは1回ロード。セクションごとに `base_seed + index` で派生シード。スケルトン MIDI の保存はしない。

## 既知の弱点

BメロとAメロは進行固定のため密度だけでは区別しにくい。煙テスト後に「Bメロだけ別進行」か「テンプレからBメロ除去」を選ぶ。

## 入口

`prttype/generate_form.py`（雰囲気文 → prior → 構成 → バッキング連結）
