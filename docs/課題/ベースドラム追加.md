# ベース・ドラム追加計画

> 最終更新: 2026-08-01

## 方針

ギター（backing/lead）と同型の経路でベースとドラムを追加する。

```
文 → prior → generate_form
               ├─ Backing U-Net   (既存)
               ├─ Lead U-Net      (既存)
               ├─ Bass U-Net      ← 追加
               └─ Drum U-Net      ← 追加
                       ↓
               4トラック MIDI → ViTex注釈（後段）
```

- **ViTex**: 生成後の注釈（コード／hyperscore）。全パート対象。D3PM は使わない
- **モデル分離**: backing/lead と同様に Bass と Drum を別 U-Net とする
- **同時着手**: 進行・キー・BPM・energy が共通なので form 統合時にズレない

---

## 表現まわり

| パート | MIDI | ViTex パッチ |
|---|---|---|
| Bass | program ≈ 33（GM Bass, category 4） | tonal 11ch の category 4 を利用 |
| Drum | `is_drum=True` | 既存 `drum (1,128,128)` チャンネル |

現行 `midi_to_patch.py` は drum を既に分離取得できる。不足しているのは **合成・学習・推論入口**。

## 実装ステップ

### Step 1: 合成データ定義（makeData）

`prttype/makeData/` に追加:

- **Bass**: コードルート中心の単音ライン。energy（low/mid/high）で密度を変える
- **Drum**: GM キット簡易パターン（kick/snare/hat）。BPM・energy でバリエーション
- 1曲あたり同一 progression / key / BPM / bars で生成
- 出力: `data/raw/synthetic_bass/` と `data/raw/synthetic_drum/`
- `docs/データ/データセット.md` を同ターン更新

### Step 2: 学習（Colab 同時トグル）

`colab_train/colab_train.ipynb` に `TRAIN_BASS` / `TRAIN_DRUM` を追加:

- **Bass**: 既存 `train.py` の tonal U-Net（12ch BPM 条件）。出力 category を bass に制限
- **Drum**: `train.py` / `inference.py` に drum モード（in/out 1ch）。guitar_only 経路とは分離
- ckpt 配置: `checkpoints/bass/unet_last.pt` / `checkpoints/drum/unet_last.pt`

### Step 3: 推論 + form 統合

- `generate_bass_music()` / `generate_drum_music()` を追加（memory 返却・model 再利用）
- `generate_form.py` のセクションループで4パート生成 → `_shift_and_merge`
- CLI: `--bass-ckpt` / `--drum-ckpt` / `--no-bass` / `--no-drum`
- `song_form.ENERGY_DECODE_PARAMS` に bass/drum 用パラメータ追加

### Step 4: ドキュメント更新

- `final-generation-form.mdc`: 「ギターのみ」→ 全4パート + ViTex注釈に更新
- `implementation-roadmap.md`: bass/drum Phase を追記
- HANDOFF 更新

## 別途検討: prior の emotion ラベル改善

現在 prior は `joy/sadness/calm/tension` の4ラベルで条件付けしているが、
WRIME の `top_label`（joy/sadness/anticipation/fear 等8ラベル）をそのまま利用する案（案A）を検討中。

- prior と accept データを WRIME 8ラベル体系で**再学習**する
- 分類器（`emotion_clf.pt`）が不要になる
- 「アップテンポな曲」→ WRIME top が joy → prior に直接渡せる

この改善は bass/drum 追加とは独立して進められる。
