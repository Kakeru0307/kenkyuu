# 対抗研究との比較

## 前提

- ユーザーが渡すのは、音楽用語のない日本語の雰囲気だけ
- キー、コード、BPM はユーザーが指定しない
- これは実施結果ではなく、どこで勝つかを決めたメモ

## 比較相手

MIDI を出力し、数分の曲を生成でき、コードが公開されているもの。

- M⁶(GPT)³。Pocwiardowski et al., 2024。https://arxiv.org/abs/2409.12638。英語の自由文からマルチトラック MIDI。内部で valence/arousal を使う。Mood matching・Q1〜O1・FAD/MAD を全軸で比べる
- Whole-song-gen。Wang et al., 2024。https://arxiv.org/abs/2405.09901。最大256小節。文の入力なし。ポップ系で学習しており音楽スタイルが異なる。Q1〜O1・FAD/MAD のみ比べる。スタイル差は論文中に注記する

## 渡し方

- M⁶(GPT)³ には、同じ日本語の雰囲気文を英語に訳して渡す。キー、コード名、BPM は足さない
- Whole-song-gen は文の入力がないため、Q1〜O1 と FAD/MAD の比較のみ行う

## 自動の評価

### FAD と MAD

採用根拠

- 音声生成12モデルを2500人以上に聴き比べさせた研究で、試した自動指標のうち音楽で学習した CLAP 埋め込みの FAD が、人の好みの順位と最も合っていた。出典: arXiv:2506.19085
- 複数の自動指標と人の好みデータ MusicPrefs を比べた研究で、FAD の順位相関は0.14、MAD は0.62だった。MAD の方が人の好みに近い。出典: arXiv:2503.16669

計算の仕組み

FAD
- WAV を CLAP モデルに通し、音楽と言葉の対応で学習した数値ベクトルに変換する
- 生成した曲の集合のベクトル分布と、参照の集合のベクトル分布の Fréchet 距離を計算する
- 低いほど参照に近い

MAD
- WAV を MERT に通す。MERT は音楽だけで自己教師あり学習したモデルで、音楽の構造やパターンを数値に変換することに特化している
- 生成と参照の分布の距離を MAUVE で計算する。MAUVE はテキスト生成の評価から転用した分布比較の手法
- 低いほど参照に近い
- FAD より人の好みとの対応が高いが、MERT は大きなモデルのため計算が重い

手順

1. 同じ日本語のプロンプトを、こちらと各相手に渡して MIDI を生成する
2. 全パートを同じ SoundFont でミックスして WAV に書き出す
3. 参照として、DadaGP のロック・メタル系の MIDI を同じ SoundFont で書き出したものを用意する
4. FAD は CLAP、MAD は MERT に WAV を通して数値に変換する
5. 分布の距離を計算する。FAD は Fréchet 距離、MAD は MAUVE

読み方

- 1曲ずつの点数は出ない。100曲以上をまとめて計算する
- FAD と MAD の両方でこちらが低ければ、参照に近いという主張を強くできる

注意

- 参照も同じ SoundFont で書いた MIDI にする。実録音や Suno を参照にしない
- キー一致、コード一致、テンポ一致はここに含まれない

## 人が聴く評価

手順

1. こちらと相手の MIDI を同じ SoundFont で書き出した WAV を評価者に聴かせる
2. 同じ日本語のプロンプトを提示した上で、各軸を1から5で評定させる
3. 評価者1人あたり複数の曲ペアを聴かせ、順序はランダムにする
4. どちらがこちらかは隠す

軸

- Q1: Melodiousness。旋律として音楽的・調和的に聞こえるか
- Q2: Rhythmicity。拍・リズムにまとまりがあるか
- Q3: Structureness。反復や展開など、構造的なまとまりがあるか
- Q4: Correctness。突然の無音・不自然な飛びなど、技術的破綻が少ないか
- O1: Overall。総合的な聴感品質への満足度
- Mood matching。その日本語の雰囲気に合っているか（M⁶(GPT)³ との比較のみ）
- 象限一致。評価者が感じた明るさと激しさが、狙いの象限に入った割合（M⁶(GPT)³ との比較のみ）

出典: Chu et al., CIKM 2022

## 主張

- 音楽用語のない日本語だけで、狙いの雰囲気に合った数分の MIDI を出す
- M⁶(GPT)³ は英語で詳細な構造まで書いた条件で動く。入力条件の差を明記した上で比べる
- Q1〜O1 で同等以上、Mood matching と象限一致で M⁶(GPT)³ より上を目標とする
