# ベースMIDI確認結果

確認対象: `kenkyuu/prttype/data/ベース/`  
判定方針: 音程・スケール・小節数はPython側で補正可能。**奏法の型（必須条件）が入っているか**を主に見る。

---

## 作り直しが必要（型がない / 未提出）

| 奏法 | 問題点 |
|---|---|
| スライド | 前後の音が重なっていない。スライドではなく通常の音符切り替えになっている |
| ハンマリング | 重ね入力がない。上昇＋2音目ベロシティ低下の型が取れていない |
| プリング | 重ね入力がない。下降＋2音目ベロシティ低下の型が取れていない |
| チョーキング | ピッチベンドが一切ない。長いノートだけになっている |
| ビブラート | ピッチベンドが一切ない。単音が鳴っているだけ |
| 浅いチョーキング | 未提出 |
| タッピング | フォルダはあるがMIDI未提出 |
| トリル | フォルダはあるがMIDI未提出 |

---

## 軽微（直すか、こちらで補正可能）

| 奏法 | 問題点 |
|---|---|
| ゴーストノート | 弱音（vel≤30）の型はある。スケール外の音あり |
| トレモロピッキング | ほぼ同一ピッチ連打だが、半音違う音が混入 |
| ナチュラルハーモニクス | 音高がベース音域外（G4付近）。音域内に直せば可 |

---

## 大きな問題なし

| 奏法 | 備考 |
|---|---|
| パームミュート | 型として欠落なし |
| スタッカート | 短い音符として成立 |
| スラップ | 必須条件なし。極端な破綻なし（wav同梱あり） |
| プル | 必須条件なし。極端な破綻なし |

---

## 友人への修正依頼（優先）

1. スライド / ハンマリング / プリング / タッピング  
   → 前後の音を途切れないよう重ねて入力する
2. 浅いチョーキング / チョーキング / ビブラート  
   → ピッチベンドカーブを入れる
3. トリル / タッピング / 浅いチョーキング  
   → 未提出分を作成する

音の並びやキーはこちらで増やせるので、**必須条件だけ守った1本**で十分。
