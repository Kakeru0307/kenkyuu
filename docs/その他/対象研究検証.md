## Whole-song-gen　Wang et al., 2024

リポジトリ: https://github.com/ZZWaang/whole-song-gen  
論文: https://arxiv.org/abs/2405.09901

### 動作確認の前提

- OpenAI の API キーは不要。事前学習済みモデルをダウンロードするだけで動く
- `inference_whole_song.py` というスクリプト1本で n 曲まとめて生成できる
- ランダム生成モードなら条件なしで 100 曲まとめて出力できる
- **ローカル GPU が無い場合は Colab GPU で実行する**（拡散4段のため CPU は非推奨）

### Colab 手順（推奨）

ノートブック: [`enemy/whole_song_gen/colab_infer.ipynb`](../../enemy/whole_song_gen/colab_infer.ipynb)（push 先: https://github.com/Kakeru0307/enemy）

1. Colab にノートを上げる（または GitHub から Open in Colab）
2. Runtime → Change runtime type → **GPU**
3. セルを上から実行
   - Drive マウント
   - `pretty_midi` / `labml` / `gdown` を入れる（既存 torch は触らない）
   - 公式リポを clone
   - Drive の公式 ckpt（`pretrained_models` + `results_default`）を取得し展開
   - `model/__init__.py` の欠落 `import os` をパッチ
   - `inference_whole_song.py --nsample N` を実行
   - 生成 MIDI を Drive（`whole_song_gen_out/`）へ退避
4. 試験は `NSAMPLE=2`、比較用は `NSAMPLE=100`

Drive キャッシュ

- 重み: `MyDrive/whole_song_gen_ckpt/`
- 生成物: `MyDrive/whole_song_gen_out/`

### ローカル手順（GPU がある場合）

1. リポジトリをクローンする
2. `pretrained_models/download_link.txt` と `results_default/download_link.txt` のリンクからモデルを取得して展開する
3. `pip install pretty_midi labml`
4. `python inference_whole_song.py --nsample 100` を実行する

### 懸念点

- テキスト入力に対応していない。文の入力なしでランダム生成する
- ポップ系で学習しているため、ギターバンド系の参照セットとの FAD/MAD ではスタイル差が出る
- 公式に `requirements.txt` が無く、依存は import から再構成する必要がある
- upstream の `model/__init__.py` に `import os` 欠落あり（Colab ノートでパッチ）
