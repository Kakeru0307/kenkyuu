## Whole-song-gen　Wang et al., 2024

リポジトリ: https://github.com/ZZWaang/whole-song-gen

### 動作確認の前提

- OpenAI の API キーは不要。事前学習済みモデルをダウンロードするだけで動く
- `inference_whole_song.py` というスクリプト1本で n 曲まとめて生成できる
- ランダム生成モードなら条件なしで 100 曲まとめて出力できる

### 動作手順

1. リポジトリをクローンする
2. `download_link.txt` に記載のリンクからモデルファイルを取得して `pretrained_models/` に置く
3. `python inference_whole_song.py --nsample 100` を実行する

### 懸念点

- テキスト入力に対応していない。文の入力なしでランダム生成する
- ポップ系で学習しているため、ギターバンド系の参照セットとの FAD/MAD ではスタイル差が出る

### 対応状況

- 未着手
