# 感情分析の改善

## 今の経路

- 文は公開の WRIME モデルに入れ、8感情の強さだけが出る
- 明るさと激しさは、その8個を固定の表で加重平均した値である
- 曲条件モデルには、8感情のうしろにその2個を足した10個を渡している
- 10個でも、明るさと激しさ以上の情報は増えていない
- 曲条件モデルが、進行・キー・テンポの傾向を選ぶ
- ギターの生成は、その曲の色を受け取る。8感情は直接見ていない

## 方針

- 感情モデルは一から作らず、今の公開モデルを初期値にして追加学習する
- 足すのは単語ではなく、曲の雰囲気を言った文である
- 「アップテンポ」「ゆったり」は激しさだけを動かす
- 「明るい」「暗い」は明るさだけを動かす
- 「しんみり」は暗く、かつ穏やかにする
- 「ジャズっぽく」のうち、速さやノリとして読める部分だけを激しさに入れる
- 跳ねや和音の種類は感情に入れない
- 8感情を出したあと、表で出た明るさや激しさのうち、その語が指定した側だけを置き換える
- 曲条件モデルの入力は10個のままである。層は増やさない
- 出力の数値が変わるので、文を付け直して曲条件モデルは再学習する

## 効果

- いい改善である。文と曲の色がずれるところに直接効く
- 「アップテンポ」は明るさまでは上がらなくなる。テンポの傾向だけが上がる
- 「ゆったり」は暗くならなくなる。テンポの傾向だけが下がる
- 「悲しい」「嬉しい」のように、すでに感情として読める文ではほとんど変わらない
- ギターのフレーズ、弾きやすさ、サビの構成は良くならない
- 雰囲気の一致は、音楽の言い方をした文に限って上がり得る
