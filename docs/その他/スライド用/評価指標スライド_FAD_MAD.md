# スライド 1

## FAD と MAD　自動評価指標の概要

生成した音楽が「人が好む音楽の分布に近いか」を自動で測る指標。

- 1曲ずつに点数は付かない。100曲以上をまとめて1つの値を出す
- 値が小さいほど、参照の音楽に近い分布であることを示す
- 人が聴いて好むかどうかと対応している根拠が論文で示されている

# スライド 2

## FAD　フレシェ音声距離とは

### 背景にあるモデル　CLAP

CLAP は「音楽」と「その音楽を説明するテキスト」の大量のペアで対照学習したモデルです。
音楽を 512 次元の数値ベクトルに変換します。
「明るい曲」「激しい曲」のような意味的な特徴も数値に反映されます。

### ベクトル化のイメージ

```
WAV ファイル → CLAP エンコーダ → 512次元ベクトル
例: [0.12, -0.34, 0.87, ..., 0.05]
```

100曲分を処理すると、100個の512次元ベクトルが得られる。
これをまとめて1つの多変量正規分布として近似する。

### FAD の計算式

FAD = ‖m₁ − m₂‖² + Tr(Σ₁ + Σ₂ − 2√(Σ₁Σ₂))

- m₁: 参照の曲のベクトルの平均
- m₂: 生成した曲のベクトルの平均
- Σ₁, Σ₂: 参照・生成それぞれの分布の広がり方
- Tr: 行列の対角成分の合計
- 第1項: 平均の位置のずれ
- 第2項: 分布の広がり方のずれ

### 値の読み方

| FAD の値 | 意味 |
|---|---|
| 小さい | 生成した曲の分布が参照の分布に近い |
| 大きい | 生成した曲の分布が参照の分布から遠い |

# スライド 3

## MAD　マウブ音声発散とは

### 背景にあるモデル　MERT

MERT は音楽データだけでマスク予測の自己教師あり学習をしたモデルです。
テキストとの対応は学習していません。
音楽の構造・リズム・音高パターンを捉えることに特化しています。

### ベクトル化のイメージ

```
WAV ファイル → MERT エンコーダ → 音楽特徴ベクトル
```

100曲分を処理すると、100個の音楽特徴ベクトルが得られる。

### MAUVE による分布比較

MAUVE はテキスト生成の評価から転用した手法です。

### MAD の計算式

混合分布: r = a・P + (1−a)・Q　（a を 0 から 1 まで変化）

D₁ = KL(Q ‖ r)　　D₂ = KL(P ‖ r)

MAD = D₁ と D₂ を縦横にプロットした曲線の下の面積から算出

- P: 生成した曲の分布
- Q: 参照の曲の分布
- a: 混合の割合
- KL: 2つの分布の違いの大きさ
- 分布が一致するほど面積が大きく、距離としては小さい値になる

### 値の読み方

| MAD の値 | 意味 |
|---|---|
| 小さい | 生成した曲の分布が参照の分布に近い |
| 大きい | 生成した曲の分布が参照の分布から遠い |

# スライド 4

## FAD と MAD を採用する根拠

### 根拠 1　FAD と人の好みとの対応

音声生成モデル 12 種類を 2,500 人以上に聴き比べさせた実験があります。
試したさまざまな自動指標のうち、CLAP を使った FAD が人の好みの順位と最も対応していました。

出典: arXiv:2506.19085

### 根拠 2　MAD は FAD より人の好みとの対応が高い

複数の自動指標と人の好みデータを比較した研究があります。
FAD の人の好みとの順位相関は 0.14 でした。
MAD の人の好みとの順位相関は 0.62 でした。

出典: arXiv:2503.16669

### まとめ

| 指標 | 人の好みとの順位相関 |
|---|---|
| FAD | 0.14 |
| MAD | 0.62 |

MAD が主指標。FAD を補助として両方を報告することで主張を強くする。

# スライド 5

## FAD と MAD の比較

| 項目 | FAD | MAD |
|---|---|---|
| 使うモデル | CLAP | MERT |
| モデルの特徴 | 音楽とテキストの対応で学習 | 音楽だけで学習 |
| 捉える側面 | 意味的な雰囲気の近さ | 音楽的な構造・パターンの近さ |
| 人の好みとの相関 | 0.14 | 0.62 |
| 計算の重さ | 比較的軽い | MERT が大きいため重い |
| 主か補助か | 補助 | 主指標 |

### 両方使う理由

異なる仕組みのモデルで計算した両方の値がこの研究に有利であれば、「意味的にも音楽的にも参照に近い」という二重の根拠になる。
