## 概要

| 層 | 指標 | 出典 | 役割 |
|---|---|---|---|
| **客観（自動）** | M1–M4（MusPy） | Yang & Lerch 2020 / MusPy | 技術的妥当性の確認 |
| **主観（人間）** | Q1–Q4 + O1 | Chu et al. CIKM 2022 | 聴感品質の評価 |
| **参考（未採用）** | M5 OA/KLD | Yang & Lerch 2020 | 参照コーパス要・必要時のみ |

**重要な前提**: 客観指標は「壊れていないか（技術的妥当性）」を見るものであり、「良い音楽か（美学的優劣）」の定義には使わない。

## 客観指標（M1–M4）

実装: `prttype/evaluate_midi.py`  
実行: `python prttype/evaluate_midi.py <file.mid> --key <KEY> --mode <MODE>`

### M1: pitch_in_scale_rate（調内音割合）

**計算方法**

```
調内音のノート数 / 全ノート数
```

指定されたキー・モードのスケール音（7音）に含まれるノートの割合。

**見るもの**: 調性の破綻が少ないか  
**優位性**: キー・モードを生成条件として与えているため、それが守られているかの直接チェックになる。1.0 が理想。

---

### M2: empty_beat_rate（空拍割合）

**計算方法**

```
音符が1つも無い拍の数 / 全拍数
```

**見るもの**: スカスカ（無音過多）や異常な沈黙がないか  
**優位性**: モデルが「何も出さない」方向に崩壊している場合に即座に検知できる。0 に近いほど良い。

---

### M3: polyphony / polyphony_rate（同時発音）

**計算方法**

```
polyphony       = 全発音時点での平均同時発音数
polyphony_rate  = 同時発音が2以上の時点の割合
```

**見るもの**: 同時発音密度が学習データの分布と大きくズレていないか  
**優位性**: パワーコード（2音）主体のバッキングでは polyphony_rate ≈ 0.4–0.6 が目安。極端に低い（単音のみ）または高い（和音過剰）場合に異常を検知する。

---

### M4: scale_consistency（調の一貫性）

**計算方法**

```
全12キーでの pitch_in_scale_rate を計算し、
最も当てはまりの良いキーのスコアを返す（キー非指定でも動作）
```

**見るもの**: 曲全体を通じてキーが一定しているか  
**優位性**: M1 はキー指定必須だが、M4 はキーを自動探索するため、prior が意図しないキーを選んだ場合でも調の一貫性だけを独立して測れる。

---

### M5: OA/KLD（分布距離）※参照コーパス要・通常スキップ

**計算方法**

```
Overlap Area (OA): 生成分布と参照分布の重なり面積
KL Divergence:     参照分布からの乖離
```

Pitch class / rhythm などの特徴分布を参照コーパスと比較。

**優位性**: 「データらしさ」を定量化できる  
**制約**: 参照コーパス（大量の正解 MIDI）が必要なため、現段階では通常スキップする。

## 主観指標（Q1–Q4 + O1）

尺度: **5点リッカート**（1=全くそう思わない ～ 5=非常にそう思う）  
出典: Chu et al., *An Empirical Study on How People Perceive AI-generated Music*, CIKM 2022  
DOI: [10.1145/3511808.3557235](https://doi.org/10.1145/3511808.3557235)

| ID | 軸 | 評価者への定義文 |
|----|---|---|
| Q1 | Melodiousness | 旋律として音楽的・調和的に聞こえるか |
| Q2 | Rhythmicity | 拍・リズムにまとまりがあるか |
| Q3 | Structureness | 反復や展開など、構造的なまとまりがあるか |
| Q4 | Correctness | 突然の無音・不自然な飛びなど、技術的破綻が少ないか |
| O1 | Overall | 総合的に、この曲の聴感品質に満足できるか |

**採用理由**

- Chu 2022 はシンボリック生成向けで本研究の出力形式（MIDI）に近い
- 各軸に定義文があり、評価者間のばらつきを抑えられる
- 9軸全体から「負担が大きく本研究で分解不要な軸」を除いた最小セット  
  （除外: Creativity / Richness / Naturalness / Coherence）

---

## 客観と主観の使い分け

```
客観（M1–M4）: 自動・再現可能・毎生成で実行
  → 「壊れていないか」の足切り。M1/M4 が低い（< 0.8）なら学習崩壊を疑う

主観（Q1–O1）: 人間による聴感評価・実験ごとに実施
  → 「良い音楽か」の本判断。Q1–O1 ≤ 2 なら次の修正点を検討する
```
