# MIDI作成依頼書（ベース担当）

## 共通仕様

- ファイル形式: `.mid`
- 長さ: 8小節
- BPM: 120
- キー: Cメジャー（使う音はCメジャースケール内に限定）
- 音域: E1〜G3
- 使用音色: ベース系であれば何でもよい
- 納期: 2026年10月15日
- 報酬: 飲みおごる or 3000円 or 応相談
- 納品形式: フォルダ構成をそのままzipにして送ること
- ファイル構成:
  ```
  ベース/
  ├── スライド/
  │   └── 01.mid
  ├── ハンマリング/
  │   └── 01.mid
  └── （以下同様）
  ```

---

ピッチベンドを使う奏法がある場合、DAWのベンドレンジを **4半音** に設定すること。

| 奏法 | 必須条件 |
|---|---|
| スライド | 起点と着点の2音を音が途切れないよう繋げて入力。上昇・下降を混在させること |
| ハンマリング | 上昇方向の2音を音が途切れないよう繋げて入力。2音目のベロシティを1音目より低くすること |
| プリング | 下降方向の2音を音が途切れないよう繋げて入力。2音目のベロシティを1音目より低くすること |
| パームミュート | 特になし |
| ゴーストノート | ベロシティ30以下のノートを含むこと。通常音と混在させること |
| トリル | 特になし |
| トレモロピッキング | 同一ピッチの繰り返しであること |
| タッピング | 2音を音が途切れないよう繋げて入力。音程差は1オクターブ以上あること |
| ナチュラルハーモニクス | 実際にハーモニクスが鳴るポジションのピッチのみ使用すること |
| スタッカート | 特になし |
| 浅いチョーキング | 音を弾いた後、半音上がるようピッチベンドカーブを描くこと |
| チョーキング | 音を弾いた後、全音上がるようピッチベンドカーブを描くこと |
| ビブラート | 半音程度を上下する周期的なピッチベンドカーブを描くこと |
| スラップ | 特になし |
| プル | 特になし |
